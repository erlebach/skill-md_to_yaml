  4. Create `compiler/renderers/math.py`:
     - `render_math_inline(tex: str) -> str`: calls `latex2mathml.converter.convert(tex, display="inline")`
     - `render_math_display(tex: str) -> str`: calls `latex2mathml.converter.convert(tex, display="block")`
     - `extract_and_render_math(text: str) -> str`: uses regex to find `$$...$$` (display, greedy across lines) and `$...$` (inline, non-greedy single line). Replace each match with rendered MathML. Process display math FIRST (so `$$` isn't matched as two `$`). Return text with MathML substituted.

  5. Create `compiler/renderers/code.py`:
     - `render_code(source: str, language: str, line_numbers: bool = False, theme: str = 'dark') -> str`
     - Theme mapping: 'dark' -> 'monokai', 'light' -> 'friendly'
     - Use `get_lexer_by_name(language, stripall=True)`; fallback to `TextLexer()` on exception
     - Use `HtmlFormatter(style=style, linenos=line_numbers, cssclass='slide-code')` (scoped class per Pitfall 3)
     - `get_pygments_css(theme: str = 'dark') -> str`: returns `HtmlFormatter(style=...).get_style_defs('.slide-code')`

  6. Create `compiler/renderers/image.py`:
     - `render_image(src: str, alt_text: str, embed: bool = False, base_dir: str = '.') -> str`
     - If `embed=True`: resolve `src` relative to `base_dir`, read file, base64 encode, detect MIME from extension (.png -> image/png, .jpg/.jpeg -> image/jpeg, .gif -> image/gif), return `<img src="data:{mime};base64,{data}" alt="{alt_text}">`
     - If file not found with embed=True: print warning to stderr `f"WARNING: Image not found: {resolved_path}"`, fall back to path reference
     - If `embed=False`: return `<img src="{src}" alt="{alt_text}">`

  7. Create `compiler/renderers/svg.py`:
     - `ALLOWED_SVG_TAGS`: list from RESEARCH.md Pattern 5 (svg, g, path, circle, rect, line, text, tspan, defs, use, symbol, title, desc, polygon, polyline, ellipse, marker, clipPath, linearGradient, radialGradient, stop)
     - `ALLOWED_SVG_ATTRS`: dict mapping tag -> allowed attrs. Include: viewBox, xmlns, fill, stroke, stroke-width, d, cx, cy, r, x, y, x1, y1, x2, y2, width, height, transform, id, class, points, offset, stop-color, stop-opacity, gradientUnits, xlink:href, font-size, text-anchor, dominant-baseline
     - `sanitize_svg(raw_svg: str) -> str`: use `bleach.clean(raw_svg, tags=ALLOWED_SVG_TAGS, attributes=ALLOWED_SVG_ATTRS, strip=True)`
     - `_normalize_svg_dimensions(svg: str) -> str`: regex replace `width="..."` and `height="..."` on the `<svg` tag with `width="100%" height="auto"`, preserve `viewBox`
     - `wrap_svg_ada(svg: str, alt_text: str, slide_id: str) -> str`: sanitize, normalize dimensions, inject `role="img"` and `aria-labelledby`, inject `<title>` and `<desc>` elements after opening `<svg>` tag

  8. Create `compiler/renderers/mermaid.py`:
     - `render_mermaid(source: str, alt_text: str, slide_id: str) -> str`
     - Write source to temp .mmd file, call `subprocess.run(['mmdc', '-i', mmd_path, '-o', svg_path], check=True, capture_output=True)`
     - On `FileNotFoundError`: raise `RuntimeError("mmdc not found - install with: npm install -g @mermaid-js/mermaid-cli")`
     - Read SVG output, clean up temp files in finally block
     - Pass SVG through `wrap_svg_ada()` from svg module
     - Return wrapped SVG string

  9. Create `compiler/renderers/markdown.py`:
     - `render_markdown(text: str) -> str`: calls `markdown.markdown(text, extensions=['tables', 'fenced_code', 'attr_list', 'md_in_html'])`

  10. Run `pip install -e ".[dev]"` to install new dependencies.
