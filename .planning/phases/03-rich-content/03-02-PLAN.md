     - In `_render`, before template rendering, build a `slides_context` list:
       ```python
       slides_context = []
       for i, slide in enumerate(deck.slides):
           slide_id = f"slide-{i+1}"
           rendered_body = render_body(slide, embed_images=embed_images, theme=deck.metadata.theme) if slide.body else None

           # Layout-specific rendering
           rendered_code = None
           rendered_image = None
           rendered_svg = None
           rendered_mermaid = None

           if slide.layout == 'code' and slide.body:
               rendered_code = render_code(slide.body, slide.language, slide.line_numbers, deck.metadata.theme)
           elif slide.layout == 'figure':
               base_dir = str(Path(output_path).parent) if embed_images else '.'  # NOT available here, use '.'
               rendered_image = render_image(slide.src, slide.alt_text, embed=embed_images)
           elif slide.layout == 'diagram' and slide.body:
               # Try mermaid first (if body looks like mermaid syntax), else treat as raw SVG
               if slide.body.strip().startswith(('graph ', 'sequenceDiagram', 'classDiagram', 'flowchart ', 'erDiagram', 'gantt', 'pie ', 'gitGraph', 'stateDiagram')):
                   try:
                       rendered_mermaid = render_mermaid(slide.body, slide.alt_text, slide_id)
                   except RuntimeError as e:
                       print(str(e), file=sys.stderr)
                       rendered_mermaid = f'<div class="mermaid-error">Mermaid rendering failed: {e}</div>'
               else:
                   rendered_svg = wrap_svg_ada(slide.body, slide.alt_text, slide_id)

           slides_context.append({
               'slide': slide,
               'slide_id': slide_id,
               'rendered_body': rendered_body,
               'rendered_code': rendered_code,
               'rendered_image': rendered_image,
               'rendered_svg': rendered_svg,
               'rendered_mermaid': rendered_mermaid,
           })
       ```
     - Compute Pygments CSS: `pygments_css = get_pygments_css(deck.metadata.theme) if any(s.layout == 'code' for s in deck.slides) else ''`
     - Pass to template: `template.render(deck=deck, slides=slides_context, total=len(deck.slides), pygments_css=pygments_css)`
