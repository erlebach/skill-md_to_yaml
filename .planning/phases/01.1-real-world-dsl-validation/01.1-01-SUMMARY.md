## What Was Built

### Parametrized Test Framework

`tests/test_real_world_decks.py` uses `pytest.mark.parametrize` with `Path.glob('real_*.yaml')` to auto-discover all real-world fixtures. Two test functions:

- `test_real_world_deck_parses(deck_path)` — asserts deck parses, has slides, has metadata title
- `test_real_world_deck_layout_types_valid(deck_path)` — asserts every slide layout is non-None

### Deck 1: quantum-transformers (8 slides)

`tests/fixtures/real_quantum_transformers_impl.yaml` — Converted from HTML covering:

- `layout: title` — deck opener with subtitle
- `layout: diagram` (x2) — Classical Transformer encoder SVG, Quantum Transformer architecture SVG
- `layout: two-column` (x2) — Quantum Self-Attention (diagram + code), Layer Normalization (formulas + code)
- `layout: code` (x2) — quantum_ffn PennyLane, QuantumResidualBlock PyTorch
- `layout: content` — Challenges with card-grid mapped to bullet list + table

### Deck 3: quixer-implementation (11 slides)

`tests/fixtures/real_quixer_implementation.yaml` — Converted from HTML covering:

- `layout: title` — deck opener
- `layout: steps` (x2) — Intuition (3-step list), Unitary Token Embedding procedure
- `layout: diagram` (x4) — Architecture pipeline, LCU circuit, PQC unit, Swap Test, Full flow
- `layout: content` — QSVT Non-linearity (formula-block mapped to content with KaTeX)
- `layout: comparison` — Pros and Cons (two-column table with `<!-- split -->`)
- `layout: summary` — Conclusions with table
