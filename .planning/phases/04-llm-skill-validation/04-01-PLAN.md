**YAML Format Reference section** — include these critical rules and examples:

CRITICAL RULES (include verbatim):
- body content goes BELOW the closing `---` separator, NEVER inside YAML frontmatter
- Slides separated by `---` lines
- First block is deck metadata (title, author, date, theme, font)
- Exactly 12 valid layout values: title, hero, content, divider, figure, diagram, two-column, quote, comparison, code, steps, summary, table
- alt_text is REQUIRED on figure and diagram layouts
- table layout uses `headers:` and `rows:` fields in YAML (NOT body content)
- diagram layout body contains raw Mermaid code WITHOUT triple-backtick fences
- No 3+ consecutive slides with the same layout type
