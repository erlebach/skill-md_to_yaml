3. Create `compiler/contrast.py` with these exact functions:
   - `hex_to_relative_luminance(hex_color: str) -> float` — W3C luminance formula: strip '#', convert to 0-1 RGB, linearize each channel (c/12.92 if c<=0.04045 else ((c+0.055)/1.055)**2.4), return 0.2126*r + 0.7152*g + 0.0722*b
   - `contrast_ratio(fg: str, bg: str) -> float` — compute luminance of both, return (lighter+0.05)/(darker+0.05)
   - `passes_wcag_aa(fg: str, bg: str, large_text: bool = False) -> bool` — ratio >= 3.0 if large_text else >= 4.5

4. Create `compiler/validators.py` with:
   - `THEME_BACKGROUNDS = {'dark': '#0d1117', 'light': '#ffffff'}`
   - `validate_deck(deck: Deck) -> tuple[list[str], list[str]]` — returns (errors, warnings). Calls all sub-validators below:
   - `_check_alt_text(slides) -> list[str]` — iterate slides; for layouts 'figure' and 'diagram', check `hasattr(slide, 'alt_text') and slide.alt_text`; for 'two-column', check left/right ColumnContent where type is 'figure' or 'diagram' and alt_text is None/empty. Return error strings like `**ERROR** slide {i}: missing alt_text on {slide.layout} slide`
   - `_check_contrast(metadata: DeckMetadata) -> list[str]` — if metadata.accent_color is not None, validate contrast_ratio(accent_color, THEME_BACKGROUNDS[metadata.theme]) >= 4.5 (or 3.0 for large text — use 4.5 as the strict check). Return error: `**ERROR** accent_color {color} fails WCAG 2.1 AA contrast ({ratio:.2f}:1) against {theme} background {bg}`
   - `_check_layout_variety(slides) -> list[str]` — track consecutive run of same layout; when run reaches 3, emit warning: `**WARNING** slides {start}-{end}: 3+ consecutive '{layout}' layout slides`
   - `_check_bullet_limits(slides) -> list[str]` — for each slide with body, count lines matching `^[-*+] ` or `^\d+\. ` via `re.findall(r'^[-*+] |^\d+\. ', body, re.MULTILINE)`; if count > 5, emit warning: `**WARNING** slide {i}: {n} bullet points exceeds recommended maximum of 5`
   - errors = _check_alt_text + _check_contrast; warnings = _check_layout_variety + _check_bullet_limits

   """CLI entry point: python -m compiler input.yaml output.html"""

       parser.add_argument("input", help="Input YAML deck file path")

       from schema.parser import parse_deck_file
       from compiler.engine import compile_deck
       deck = parse_deck_file(args.input)
       compile_deck(deck, args.output)
