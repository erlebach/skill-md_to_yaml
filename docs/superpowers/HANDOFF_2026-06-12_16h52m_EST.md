## Decisions locked

- **Missing diagram source = WARNING, not error** — user chose; joins the design-warning channel so the zero-warnings QA loop flags it without breaking legacy decks.
- **In-panel column headings scale with `content_scale`; only the slide h2 follows `title_scale`** — so the panel resizes as one unit.
- **Two-col diagram panel band: maximum by default (16px gap / 48px bottom), shrink per slide via `panel_scale`** — "maximum so I can decrease it"; the universal formula is deferred to the user. - **`content_scale` on an overfull slide buys nothing** — text grows, autofit (shrink-only, final say — reaffirmed) zooms the slide back; figures take the full zoom hit because Mermaid sizing runs pre-autofit at zoom 1 (ordering locked, inflation bug). - **Mermaid subgraph-label clipping is systematic** — any wrapped subgraph title gets its second line clipped (seen on two unrelated slides); belongs in the sizing JS, not in shortening labels per-fixture.
