Effective Presentations

Design Principles for Clear, Engaging Slides

One Idea Per Slide, Every Time

Every strong slide carries exactly one clear message — the layout reinforces it, and the speaker supplies the detail.

Build a Narrative Arc

  • Through-line: each slide connects logically to the one before
  • State: introduce the learning objective up front
  • Illustrate: show a figure, diagram, table, or example
  • Derive: explain why it matters or what follows next

The State → Illustrate → Derive Cycle

Bullets Are Memory Cues, Not a Script

  • 5×5 rule: aim for ≤ 5 bullets, ~5 words each — 8 is the hard ceiling
  • One idea per bullet: split if a bullet contains "and" twice
  • Parallel structure: all bullets start with the same part of speech
  • Short phrases: avoid wrapping past two lines

Layout Types at a Glance

Every Presentation Has the Same Skeleton

  1. Open — title slide, then a hook or agenda, then problem context
  2. Body — 4–8 content slides per section; vary layouts throughout
  3. Close — key-takeaway summary, then a call to action

Variety Signals Importance

  • 3-slide rule: never repeat the same layout more than 3 times in a row
  • Layout change = attention cue — the audience notices a shift
  • 10-second test: the main point should be graspable in under 10 seconds
  • Simplification test: ask whether a complex layout truly serves the message

Key Takeaways

  • One primary message per slide — split rather than cram
  • Build a repeating arc: state → illustrate → derive
  • Short, parallel bullets keep slides readable at distance
  • Vary layouts deliberately to signal topic shifts
  • Test: can the audience grasp the main point in 10 seconds?
