# *Here is where I have a problem: "The complication comes when you repeat the experiment many times, or test many hypotheses, or try many ways of analyzing the data. Then unusual-looking results are no longer so impressive, because randomness gets many opportunities to create one. In other words, the more chances you give chance, the more likely it is that something extreme will eventually show up somewhere." Yes, if you simply count the unusual results and don't provide the number of experiments conducted, then the results are no longer as impressive. But if the total count is provided, the results are identical to the single experiment case.*
----------------------------------------------------------------------
Yes. In the sense you mean, that is exactly right.

If you report the full set of experiments, including how many were run, then nothing mysterious has happened. The unusual result has not changed. Its per-experiment probability is the same as it always was. A one-in-a-thousand event is still a one-in-a-thousand event. Running 10,000 experiments does not make that event less rare within any single experiment.

So if the question is simply, “How rare was this outcome in one trial?” then the answer is identical to the single-experiment case. On that point, I agree with you.

The place where the interpretation changes is when someone wants to use one standout result as evidence. Then the relevant question is no longer just, “How rare is this result in one experiment?” It becomes, “How rare is it that, after running all these experiments, at least one result this extreme would show up somewhere just by chance?” That is a different question.

So there are really two different uses of the same data. One use is descriptive: this particular outcome has probability 0.001 in a single run. That remains true. The other use is inferential: should I treat this observed standout result as strong evidence against the null? That answer depends on how many chances there were for a standout result to appear.

A simple way to say it is this. If you show me all 10,000 runs and say, “One of them came out extreme,” I am not impressed, because with 10,000 runs I would expect that to happen sometimes by chance. But if you show me one pre-specified run and say, “This one came out extreme,” that carries more weight. The numerical rarity of the outcome did not change. What changed is the meaning of seeing it in the context of a large search.

So your objection is a good one if someone says, “The result itself is no longer rare.” That would be wrong. The result is just as rare as before. What becomes less impressive is the claim that this result, once selected from many attempts, is strong evidence of something real.

Another way to put it is that full disclosure solves part of the problem, but not all of it. Full disclosure tells us the correct context. Once that context is known, we should no longer judge the extreme result as though it came from a single isolated trial. We judge it as the most extreme outcome from a larger collection. That is why the evidential assessment changes.

So the clean version is this: the outcome itself is identical to the single-experiment case, but the inference you draw from having observed it is not identical once you know it came from many opportunities. That is the heart of multiple testing.

Your formulation is actually a very good correction to sloppy teaching. The issue is not that rare results stop being rare. The issue is that a rare result selected from many trials is weaker evidence than the same rare result from one pre-specified trial.
